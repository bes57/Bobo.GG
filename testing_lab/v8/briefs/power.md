## Work
1. **MDE, overall.** From per-series ΔLL vectors d = ll_v6 − ll_candidate for
   every v7 config: estimate σ_d per pair; MDE_80@0.05 = (z_.975+z_.80)·σ_d/√n
   ≈ 2.80·σ_d/√n, AND verify by simulation (inject shift μ into recentered d,
   measure rejection rate with the actual paired-bootstrap procedure). Report
   the spread of MDE across pairs (σ_d varies with how correlated the configs
   are). State clearly which MDE applies to "two decay variants" vs "two
   structurally different models" (σ_d differs; measure both regimes).
2. **MDE per bucket**, same machinery on bucket subsets, with bucket n's.
3. **v7 ladder re-adjudication.** For each of the 18+6 configs vs v6: mean Δ,
   CI (iid + block-by-event), P(better), and verdict DISTINGUISHABLE /
   INSIDE NOISE FLOOR at the measured MDE. The brief's motivating cases —
   sym_20 (−1.65 milli claimed, P 0.14) and consist_16_10 (−0.39 milli,
   P 0.28) — must appear explicitly with your recomputed numbers.
4. **Ledger reclassification.** Every one of the 33 entries: old verdict, the
   ΔLL magnitude it was rejected at (recover from out/*.json; mark
   UNRECOVERABLE honestly where the number isn't on disk), MDE at time of
   test, new status REFUTED / UNRESOLVED / CONFIRMED. Entries rejected on
   mechanism grounds (bugs like the v5 asymmetry, double-counting like
   per-map+pick) stay REFUTED regardless of magnitude — flag them as
   mechanism-rejected. Output the sortable table JSON for the future page.
5. **Variance reduction, first-class.** Quantify: (a) pairing vs unpaired
   variance ratio on real config pairs; (b) control variate: v6 per-series
   loss as covariate — residualize d against (ll_v6 − mean) and report the
   variance ratio and the equivalent effective-n multiplier; (c) blocking by
   event; (d) any further design you can defend. Report each as an
   effective-sample-size multiplier with the method written down.
6. **crn.json** — write FIRST (others depend on it): {bootstrap: {generator:
   "numpy PCG64", seed, n_boot}, block_bootstrap: {seed, unit: "event_id"},
   mc_seeds: [pool of 64 ints], holdout_order: canonical (date, match_id)
   list of holdout match_ids, verify: {first100_iid_indices_sha256: ...}}.
   Include enough that an independent agent reproduces identical resamples.
